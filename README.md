# Skriuw Scoop bucket

Scoop bucket for [Skriuw](https://skriuw.com), the local-first workspace for notes, journaling, and connected knowledge. Source and releases live in [remcostoeten/skriuw](https://github.com/remcostoeten/skriuw).

```powershell
scoop bucket add skriuw https://github.com/skriuw/scoop-bucket
scoop install skriuw
```

macOS users install from [skriuw/homebrew-tap](https://github.com/skriuw/homebrew-tap). Linux packages (apt, dnf, AUR, Snap) and direct downloads are listed on [skriuw.com/download](https://skriuw.com/download/).

The manifest is updated automatically when a v2 release is published. Do not edit `version` or the hash by hand.
